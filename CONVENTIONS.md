## Семантическая разметка

При генерации нового кода и рефакторинге существующего, добавь семантические якоря на смысловые блоки, которые помогут тебе лучше ориентироваться в структуре кода.

### Формат якорей

- Открывающий: // <name_block> Краткое описание
- Закрывающий: // </name_block>
- Для критических блоков добавь "not delete"

### Правила разметки

1. Валидация входных параметров: <validation>
2. Проверка прав доступа: <security>
3. Запросы к БД: <query> или <selection>
4. Основная бизнес-логика: <processing> или <calculate>
5. Обработка ошибок: <error>
6. Логирование: <log>, <ai_log>
7. Кэширование: <cach>

### Порядок работы

1. Определи логические блоки процедуры или алгоритма, с которыи работаешь
2. Каждому блоку назначь якорь из списка (или создай новый по аналогии)
3. Критические блоки (валидация, безопасность, обработка ошибок) пометь «not delete»

### Пример

```bsl
<security> Обработка валидации эл.адреса - not delete
    (код на языке 1С)
</security>
```

## Few-shorts

### Комментарий к экспортной функции

```bsl
// Краткое описание (1-2 предложения).
//
// Параметры:
//  ИмяПараметра - Тип - описание. Если параметр необязательный — указать значение по умолчанию.
//
// Возвращаемое значение:
//  Тип - описание.
//
// Пример:
//  Результат = ИмяФункции(Параметры);
```
