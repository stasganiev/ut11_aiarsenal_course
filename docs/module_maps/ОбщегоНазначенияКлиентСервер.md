# Карта модуля: ОбщегоНазначенияКлиентСервер

## Назначение
- Общий модуль БСП, исполняемый и на клиенте, и на сервере (Клиент управляемого приложения + Сервер + ВнешнееСоединение, без ВызовСервера). Утилиты, не требующие обращения к БД: работа с коллекциями, строками, файлами, адресами почты, версиями, формами/динамическими списками, табличными документами, датами для HTTP, проверка типов.
- Кэш повторного использования отключён (`ReturnValuesReuse = DontUse`). Прямых обращений к объектам БД нет.

## Внешние зависимости (объекты БД)
- Нет. Модуль не обращается к Справочникам/Документам/Регистрам/Константам напрямую (клиент-серверный, работает с переданными данными и платформенными объектами).

## Ключевые контракты (нельзя менять без последствий)
- Сигнатуры и поведение экспортного API — типовой модуль БСП, вызывается с клиента и сервера всей конфигурацией; изменение ломает совместимость и затирается при обновлении БСП.
- Функции должны оставаться исполнимыми и на клиенте, и на сервере: нельзя вводить серверозависимый код (запросы, обращения к БД) — для этого есть `ОбщегоНазначения`.
- `СравнитьВерсии` / `*БезНомераСборки` — контракт знака результата (<0, 0, >0) используется в логике обновлений.
- `РаспределитьСуммоПропорциональноКоэффициентам` — алгоритм распределения с учётом точности влияет на суммовые расчёты; менять нельзя.
- При доработке конфигурации на поддержке расширять через `*Клиент`/`*Переопределяемый`, а не правкой этого модуля.
