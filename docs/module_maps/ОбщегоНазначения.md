# Карта модуля: ОбщегоНазначения

## Назначение
- Серверный общий модуль БСП (Сервер + ВнешнееСоединение, без ВызовСервера). Базовая инфраструктура: чтение/запись реквизитов объектов, поиск и замена ссылок, метаданные, хранилища настроек, безопасное хранилище, сериализация XML/JSON, веб-сервисы, безопасное выполнение кода, окружение.
- НЕ для прямого вызова с клиента (`ServerCall = false`). Кэш повторного использования отключён (`ReturnValuesReuse = DontUse`).

## Ключевые контракты (нельзя менять без последствий)
- Сигнатуры и поведение экспортного API — модуль типовой БСП, вызывается из всей конфигурации и других модулей библиотеки; любое изменение ломает совместимость и затирается при обновлении БСП.
- `ЗначениеРеквизитаОбъекта` / `ЗначенияРеквизитовОбъекта` — горячий путь, используется массово; смысл `ВыбратьРазрешенные` (RLS) менять нельзя.
- `ЗаменитьСсылки` и связанный блок мест использования — транзакционная семантика и порядок обработки коллекций критичны для целостности данных.
- Модуль с `ServerCall = false` — НЕ вызывать с клиента; клиентский аналог — `ОбщегоНазначенияКлиентСервер`.
- При доработке конфигурации на поддержке: расширять через `*Переопределяемый` модули БСП, а не правкой этого модуля.
