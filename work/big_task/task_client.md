Расширить подсистему «Ценообразование» учебной торговой конфигурации:
добавить механизм автоматического формирования розничных цен по
правилам, заданным для категорий номенклатуры.

Бизнес-требования:
1. Правила задаются на уровне категории номенклатуры (одна категория —
   несколько правил с приоритетом)
2. Три типа правил:
   - ПоНаценке: РозничнаяЦена = ЗакупочнаяЦена × (1 + Наценка/100)
   - ПоКонкурентнойЦене: РозничнаяЦена = КонкурентнаяЦена × Коэффициент
   - Фиксированная: РозничнаяЦена = заданное значение
3. Минимальная наценка как защита от убытков:
   РозничнаяЦена ≥ ЗакупочнаяЦена × (1 + МинНаценка/100)
4. Округление по правилам соглашения (`Перечисление.ПравилаОкругления`)
5. Автоматический пересчёт при изменении закупочной цены

Технический контекст подсистемы:
- Подсистема ценообразования — модуль ЦенообразованиеРасчет, см. паспорт
- Базовые цены (включая новый вид «Закупочная») — РС ЦеныНоменклатуры
- Категория товара — реквизит "Категория" справочника Номенклатура
  (тип СправочникСсылка.КатегорииНоменклатуры)
- Кэширование цен — ПараметрыСеанса.КэшЦен (уже есть)
- Существующая обработка МассовоеИзменениеЦен — ручной АРМ, остаётся
