# Тест-план: Подсистема «Ценообразование»

**Версия:** 1.0  
**Дата:** 2026-05-05  
**Область:** Функция расчёта итоговой цены со скидкой, документы продаж, отчёт «Анализ цен»  
**Для кого:** QA-инженер (уровень продвинутого пользователя 1С)  
**Основание:** Карта рисков `ЦенообразованиеСервер_КартаРисков.md`, перечень тестов `Ценообразование_Тесты.md`

---

## Порядок прогона

1. Выполнить **Подготовку тестовой среды** (раздел ниже).
2. Прогнать все **P1-тесты** (TC-001 – TC-004) подряд. Если хотя бы один падает — дальнейшее тестирование остановить, сообщить QA-лиду.
3. Прогнать **P2-тесты** (TC-005 – TC-010).
4. При наличии времени — **P3-тесты** (TC-011 – TC-014) и **P4** (TC-015).

---

## Подготовка тестовой среды

> Выполняется один раз перед началом прогона. Используйте тестовую базу — не рабочую.  
> Входить под пользователем с полными правами (роль «Администратор») на время подготовки.

### Шаг 1. Номенклатура и цены

1. Откройте раздел **НСИ → Номенклатура**.
2. Создайте новую позицию: наименование **`Товар-Тест`**, тип — Товар. Запишите и закройте.
3. Откройте раздел **Продажи → Цены номенклатуры** (или **НСИ → Цены номенклатуры**).
4. Создайте новую запись:
   - Номенклатура: **`Товар-Тест`**
   - Вид цены: **`Основная`** (если нет — создайте в справочнике **Виды цен**)
   - Цена: **1 000 ₽**
   - Дата: **01.01.2025** (важно: прошедшая дата, чтобы срез работал на любую текущую дату)
   - Запишите.
5. Создайте ещё одну запись для того же `Товар-Тест` / вид цены `Основная`:
   - Цена: **1 200 ₽**
   - Дата: **01.04.2026**
   - Запишите. *(Нужна для TC-013 — проверка исторической даты.)*

### Шаг 2. Контрагент и договор

1. Откройте раздел **НСИ → Контрагенты** (или **Партнёры**).
2. Создайте контрагента: наименование **`Контрагент-Тест`**. Запишите.
3. Откройте карточку контрагента, перейдите на вкладку **Договоры**. Создайте договор:
   - Наименование: **`Договор-Тест`**
   - Ставка дисконтирования: **10%**
   - Запишите и закройте.

### Шаг 3. Константы

1. Откройте **Администрирование → Параметры учёта** (или через строку поиска — «Максимальная скидка»).
2. Установите константу **`МаксимальнаяСкидкаПоУмолчанию`** = **30**.
3. Сохраните.

### Шаг 4. Функциональная опция «Учитывать индивидуальные цены»

1. Откройте **Администрирование → Настройки продаж** (или «Функциональные возможности»).
2. Найдите опцию **«Учитывать индивидуальные цены»** — **выключите** (Ложь). Сохраните.  
   *(Включение/выключение описано в конкретных тестах по мере необходимости.)*

### Шаг 5. Индивидуальные цены (соглашения)

1. Откройте регистр **Соглашения о ценообразовании** (через меню Продажи или строку поиска).
2. Создайте запись:
   - Контрагент: **`Контрагент-Тест`**
   - Номенклатура: **`Товар-Тест`**
   - Индивидуальная цена: **700 ₽**
   - Флаг **«Активное»**: ✅ включён
   - Запишите. Назовём её **«Соглашение-700»**.

### Шаг 6. Роли для тестирования

- Для **дымовых тестов**: создайте (или используйте) пользователя **`Менеджер-Тест`** с ролью **«МенеджерПродаж»**.
- Для **TC-004** (управление константой): пользователь с ролью **«АдминистраторСкидок»**.
- Для остальных тестов — пользователь с правами на проведение документов продаж.
