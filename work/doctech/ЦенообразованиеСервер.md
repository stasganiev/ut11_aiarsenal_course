# Общий модуль «ЦенообразованиеСервер»

## Назначение

Модуль рассчитывает итоговую цену реализации единицы номенклатуры для конкретного контрагента: берёт базовую цену по виду цены, при необходимости заменяет её действующей индивидуальной ценой контрагента и применяет процент скидки, рассчитанный модулем `РасчётСкидок`, ограниченный константой `МаксимальнаяСкидкаПоУмолчанию`.

Тип модуля — серверный, с доступом из внешнего соединения, без вызова сервера и без повторного использования возвращаемых значений.

## Публичный API

| Метод | Назначение |
| --- | --- |
| `ПолучитьИтоговуюЦенуСоСкидкой(Номенклатура, Контрагент, СуммаЗаказа, ВидЦены, Договор, Дата)` | Возвращает итоговую цену единицы номенклатуры с учётом индивидуальных условий контрагента и скидки. |

## Области модуля

- **ПрограммныйИнтерфейс** — единственная публичная функция получения итоговой цены реализации со скидкой.
- **СлужебныеПроцедурыИФункции** — внутренние запросы к регистрам сведений: получение базовой цены по виду цены и действующей индивидуальной цены контрагента.

## Зависимости

### Используемые общие модули

- `РасчётСкидок.РассчитатьСкидку` — расчёт процента скидки клиента.

### Функциональные опции

- `УчитыватьИндивидуальныеЦены` — при включении подменяет базовую цену индивидуальной ценой контрагента.

### Чтение из информационной базы

- Регистр сведений `ЦеныНоменклатуры` (срез последних) — получение базовой цены по виду цены на дату.
- Регистр сведений `СоглашенияОЦенообразовании` — получение действующей индивидуальной цены контрагента.
- Константа `МаксимальнаяСкидкаПоУмолчанию` — верхняя граница итогового процента скидки.

### Запись в информационную базу

- Не выполняется. Модуль является полностью читающим.
