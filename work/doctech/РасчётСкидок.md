# Общий модуль «РасчётСкидок»

## Назначение

Модуль реализует бизнес-правила расчёта процентной скидки клиента (договорная ставка, VIP-надбавка, бонус за крупную сумму заказа, сезонная акция) и применение полученного процента ко всем строкам документа продажи. Дополнительно предоставляет функцию получения актуальной цены номенклатуры по виду цены на заданную дату.

Тип модуля — серверный, с доступом из внешнего соединения, без вызова сервера и без повторного использования возвращаемых значений.

## Публичный API

| Метод | Назначение |
| --- | --- |
| `РассчитатьСкидку(Клиент, Договор, СуммаЗаказа, ДатаЗаказа)` | Рассчитывает итоговый процент скидки клиента с учётом договора, VIP-статуса, суммы и сезонной акции. |
| `ПрименитьСкидкуКДокументу(ДокументОбъект)` | Применяет рассчитанный процент скидки ко всем строкам ТЧ «Товары» документа и пересчитывает суммы. |
| `ПолучитьАктуальнуюЦену(Номенклатура, ВидЦены, ДатаАктуальности = Неопределено)` | Возвращает цену номенклатуры по виду цены на заданную дату из регистра ЦеныНоменклатуры. |

## Области модуля

- **ПрограммныйИнтерфейс** — публичные методы расчёта скидок и получения актуальной цены.
- **СлужебныеПроцедурыИФункции** — внутренние помощники: чтение базовой ставки из договора, проверка сезонной акции, ограничение скидки допустимым диапазоном.

## Зависимости

### Используемые общие модули БСП и конфигурации

- `ОбщегоНазначения.ЗначениеРеквизитаОбъекта` — чтение реквизитов «VIP» контрагента и «СтавкаДисконтирования» договора.

### Чтение из информационной базы

- Регистр сведений `ЦеныНоменклатуры` (срез последних) — функция `ПолучитьАктуальнуюЦену`.
- Реквизит `Партнёры.VIP` — через `ОбщегоНазначения.ЗначениеРеквизитаОбъекта`.
- Реквизит `ДоговорыКонтрагентов.СтавкаДисконтирования` — через `ОбщегоНазначения.ЗначениеРеквизитаОбъекта`.
- Константа `МаксимальнаяСкидкаПоУмолчанию` — верхний предел процента скидки.

### Запись в информационную базу

- Изменения вносятся только в переданный в `ПрименитьСкидкуКДокументу` объект документа (колонки `ПроцентСкидки`, `СуммаСкидки`, `Сумма` ТЧ «Товары» и реквизит `СуммаДокумента`). Сохранение объекта остаётся за вызывающим кодом.
