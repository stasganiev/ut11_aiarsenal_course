## Назначение модуля (2 строки)

Серверный модуль расчёта цены товара для контрагента: базовая цена → скидки (категория / объём / акция / оптовая / накопительная) → правила (ограничения, округление) → запись истории. Точки входа — из документов реализации и обработки массового обновления цен.

---

## Экспортный API (сигнатуры)

```
РассчитатьЦену(Товар, Контрагент, Соглашение, ДатаРасчёта, Количество) → Структура {Цена, ПроцентСкидки, ПримененныеСкидки, Основание}
РассчитатьЦеныДокумента(Документ) → ТаблицаЗначений (+колонки ИтоговаяЦена, ПроцентСкидки)
ОбновитьЦеныПоСоглашению(Соглашение, ДатаНач, ДатаКон) → без возврата (в транзакции)
ОбработатьДокументыЗаПериод(ДатаНач, ДатаКон, Соглашение) → без возврата (массовый пересчёт документов реализации)
РассчитатьСкидку(Клиент, Договор, СуммаЗаказа, ДатаЗаказа) → Число (точка входа из Модулей 2-3)
```

## Внутренние функции (по областям)

```
БазовыеЦены:
- ПолучитьБазовуюЦену(Товар, ВидЦены, ДатаРасчёта) → Число
- ПолучитьВидЦеныПоСоглашению(Соглашение) → СправочникСсылка.ВидыЦен
- ЦенаДействуетНаДату(ЗаписьЦены, ДатаПроверки) → Булево

Скидки:
- ПолучитьСкидкиКонтрагента(Контрагент, ДатаРасчёта) → Массив структур {ТипСкидки, Процент, Основание}
- РассчитатьСкидкуПоОбъёму(Контрагент, Период) → Число
- ПроверитьАкцию(Товар, ДатаРасчёта) → Число
- ОптоваяСкидкаПоДокументу(ТабличнаяЧасть) → Число
- ПрименитьНакопительнуюСкидку(Контрагент, БазоваяСкидка) → Число

ПравилаЦенообразования:
- ПрименитьПравилаЦенообразования(Цена, Скидки, Соглашение) → Число
- ПроверитьОграничения(ИтоговаяЦена, МинимальнаяЦена, МаксимальнаяСкидка) → Число
- ОкруглитьЦену(Цена, ПравилоОкругления) → Число

СлужебныеПроцедуры:
- ПолучитьКэшЦен(Товар, ВидЦены, ДатаРасчёта) → Число|Неопределено
- ОбновитьКэшЦен(Товар, ВидЦены, ДатаРасчёта, Цена)
- ЗаписатьИсториюРасчёта(ДанныеРасчёта)
- ПодготовитьСтруктуруРезультата() → Структура
- ПолучитьБазовуюСкидку(Договор) → Число
- ОграничитьМаксимальнуюСкидку(Скидка) → Число
- СвернутьПроцентСкидки(Скидки) → Число
```

## Внешние зависимости (одной строкой)

РС `ЦеныНоменклатуры`, РН `ЗакупкиКонтрагентов`, РС `ИсторияРасчётаЦен`, справочники `СоглашенияОЦенообразовании` (+ТЧ Товары), `Акции`, перечисления `КатегорииКлиентов` (VIP/Новый/Обычный), `ПравилаОкругления` (ДоРубля/До10/Психологическое99), параметр сеанса `КэшЦен`, константа `МаксимальнаяСкидкаПоУмолчанию`.

---

## Ключевые контракты (что нельзя менять)

1. Возврат `РассчитатьЦену` — структура с полем `ПримененныеСкидки` (массив структур)
2. Возврат `ПолучитьСкидкиКонтрагента` — массив структур `{ТипСкидки, Процент, Основание}`
3. Возврат `РассчитатьСкидку` — Число (процент), совместимость с Модулями 2-3
