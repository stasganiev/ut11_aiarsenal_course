## Назначение

Серверный общий модуль расчёта цен и скидок для документов продаж: расчёт цены по соглашению с учётом скидок, пересчёт цен табличной части документа, массовое обновление цен и расчёт итоговой скидки клиента.

## Публичный API

- **РассчитатьЦену**(Товар, Контрагент, Соглашение, ДатаРасчёта, Количество) → Структура (Цена, ПроцентСкидки, ПримененныеСкидки, Основание).
- **РассчитатьЦеныДокумента**(Документ) → ТаблицаЗначений (копия табличной части Документ.Товары + колонки ИтоговаяЦена, ПроцентСкидки).
- **ОбновитьЦеныПоСоглашению**(Контрагент, ДатаНач, ДатаКон) — процедура, перезаписывает РегистрСведений.ЦеныНоменклатуры в транзакции.
- **РассчитатьСкидку**(Клиент, Договор, СуммаЗаказа, ДатаЗаказа) → Число (итоговый процент скидки).

## Архитектура (области)

- **ПрограммныйИнтерфейс** — экспортные точки входа.
- **БазовыеЦены** — получение базовой цены и вида цены, проверка актуальности на дату.
- **Скидки** — формирование массива скидок, акции, накопительная скидка, оптовая скидка.
- **ПравилаЦенообразования** — применение скидок, ограничения, округление.
- **СлужебныеПроцедуры** — кэш цен, история расчёта, формирование результата, лимит скидки.

## Бизнес-правила

Скидки собираются в массив в порядке приоритета: **Акция → Объём (3 мес) → Категория (VIP/Новый) → Постоянство (>12 мес)**. Применение через суммирование процентов. В РассчитатьЦену цена ограничивается МинимальнойЦеной соглашения, затем повторно проверяется с максимумом 25%, затем округляется. В РассчитатьЦеныДокумента после построчного расчёта применяется оптовая скидка по сумме документа ко всем строкам. Максимальная скидка ограничена константой МаксимальнаяСкидкаПоУмолчанию (фолбэк 25%).

## Критические контракты

Структура результата РассчитатьЦену фиксирована (4 поля). Возврат РассчитатьЦеныДocéкумента — ТаблицаЗначений с обязательными колонками ИтоговаяЦена и ПроцентСкидки. Порядок и состав скидок влияет на итог. Пустая ТЧ возвращает пустую ТЗ без колонок.

## Внешние зависимости

- **Регистры сведений**: ЦеныНоменклатуры, СоглашенияОЦенообразовании, ИсторияРасчётаЦен.
- **Регистр накопления**: Закупки (обороты).
- **Справочники**: ВидыЦен (Основная), Номенклатура, Акции.
- **Перечисления**: КатегорииКлиентов (VIP, Новый), ПравилаОкругления (ДоРубля, До10, Психологическое99).
- **Константы**: МаксимальнаяСкидкаПоУмолчанию.
- **ПараметрыСеанса**: КэшЦен (Соответствие по ключу Товар|ВидЦены|Дата).
- **Общие модули**: ОбщегоНазначения (ЗначениеРеквизитаОбъекта).
